# Demo Home Screen

`ios-home-screen.webp` is a screen-only crop of Apple's example iPhone Home Screen, converted to WebP.

- Source page: https://support.apple.com/guide/iphone/open-apps-iphca3d8b4e3/ios
- Original image: https://ipcdn-web.apple.com/assets/v2/web/75442b87-2342-4d3f-94e6-375015c51cf7
- Original dimensions: 490 × 1008 pixels
- Crop: left 22, top 20, right 468, bottom 986
- Image credit: Apple
